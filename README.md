# Baseball Stats App
Full stack web application built with React, Node/Express, and SQLite.

## Features
- Add and view baseball player stats
- Delete players
- AI-powered scouting report generation using Anthropic API

## Tech Stack
- Frontend: React
- Backend: Node.js + Express
- Database: SQLite (better-sqlite3)
- AI: Anthropic Claude API

## Setup
1. cd server && npm install && npm run dev
2. cd client && npm install && npm start
3. Add ANTHROPIC_API_KEY to server/.env
